# Contribution guide
## How to contribute
1.Fix bugs or optimize code

2.Make a pull request where you:
- Name all changes made to the code
- Explain what the code does
- Name all people that worked on the changes

3.That's all.

## Guidelines
Please follow the following:
- Do NOT remove original copyright headers
- Do NOT change basic structure
- No racism
- No sexism
- Dumb comments recommended !!!
